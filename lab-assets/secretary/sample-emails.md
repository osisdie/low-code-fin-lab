# 秘書練習用：11 封虛構客戶來信

> 公司、人名、信箱都是虛構的。**課堂請只用這些信練習，不要把真實客戶信件送進免費 AI 模型**（原因見 `docs/student/student-security-gmail-keys.md`）。

每封信下面都寫了「預期」：秘書判讀出的**意圖**、紀錄的**狀態**、有沒有建立**草稿**。處理完可以對照試算表「秘書紀錄」分頁或知識庫 `秘書/` 資料夾檢查。
（AI 偶爾會判讀得不一樣，例如把感謝信判成「其他」以外的意圖；不一樣時，看紀錄裡的「為什麼需要人工處理」再自己決定。）

## 怎麼用
1. 先寄 **基本 3 封**（① 詢價、⑦ 改期、⑧ 客訴）：用你自己的 Gmail **寄給自己**，主旨、內文照下面複製。
2. 在收件匣把它們貼上標籤 **AI秘書**（第一次執行秘書功能後標籤會自動出現；也可以先在 Gmail 左側「建立新標籤」）。
3. 回到試算表 → 選單「📰 我的 AI 助理」→「⑤ 秘書：處理『AI秘書』標籤的信」。
4. 有時間再寄 **進階 8 封**。⑤ 一次最多處理 5 封（避免用光免費額度），超過的再按一次 ⑤，或等每小時的 ⑥ 自動處理。

因為是寄給自己，草稿的收件人也會是你自己，不會誤寄給任何人。

## ① 詢價（多個品項，會產生報價單草稿）｜基本

**主旨**：詢價：社群代操與活動攝影

```
您好，

我是星河咖啡的陳小姐。我們 12 月要開第二家店，想請貴公司協助：
1. 社群貼文代操，先簽 3 個月
2. 開幕活動攝影，兩場（12/6、12/7 各半天）
3. 另外也想做幾支開幕短影音，不知道有沒有這項服務？

想請您在 11 月 15 日前提供報價。另外如果一起簽，請問有沒有折扣？

星河咖啡 陳小姐
```

**預期**：意圖「詢價」｜狀態「待確認草稿」｜草稿 yes

**你應該看到**：報價單草稿列出「社群貼文代操（月）× 3」「活動攝影（半天）× 2」並算出已計價品項小計；「短影音」標記「報價表查無此品項」，所以合計顯示「（未完成）」；「折扣」出現在【需人工確認】。

## ② 詢價（沒寫數量）｜進階

**主旨**：想了解品牌顧問和官網改版的費用

```
您好，

我們是山嵐設計工作室，最近想重新整理品牌形象，
想了解品牌顧問諮詢大概怎麼收費，也考慮順便把官網改版。
還沒想好要幾次諮詢，可以先給我們一個參考嗎？

山嵐設計 張先生
```

**預期**：意圖「詢價」｜狀態「待確認草稿」｜草稿 yes

**你應該看到**：報價單草稿有「品牌顧問諮詢（小時）」「官網改版方案」，數量寫「待確認」、合計「（未完成）」。程式**不會自己猜數量**。

## ③ 詢價（品項都不在報價表）｜進階

**主旨**：詢價：Podcast 剪輯與空拍

```
您好，

小島書店想做一個說書 Podcast，想請你們幫忙剪輯 10 集，
另外書店週年慶想拍一段無人機空拍影片，請問可以報價嗎？

小島書店 李店長
```

**預期**：意圖「詢價」｜狀態「待確認草稿」｜草稿 yes

**你應該看到**：報價單草稿的每個品項都是「報價表查無此品項」，沒有任何金額；草稿請你人工報價。

## ④ 英文詢價｜進階

**主旨**：Quotation request: website redesign

```
Hi,

This is Emily Chen from Harbor Lane Studio. We would like a quotation for
one website redesign package and a one-year annual maintenance contract.
Could you send it to us by December 5?

Best regards,
Emily Chen
Harbor Lane Studio
```

**預期**：意圖「詢價」｜狀態「待確認草稿」｜草稿 yes

**你應該看到**：報價單草稿有「官網改版方案 × 1」「年度維護合約 × 1」，合計完整算出（金額來自報價表）。回覆草稿可能是中文或英文，寄出前自己確認語言。

## ⑤ 發票／付款確認｜進階

**主旨**：10 月款項已匯款，麻煩開立發票

```
您好，

10 月份的官網維護費用我們已經在昨天匯款，
麻煩幫我們開立發票寄到公司信箱，謝謝。

綠島旅行社 王經理
```

**預期**：意圖「其他」｜狀態「待確認草稿」｜草稿 yes

**你應該看到**：草稿只回覆「收到、會確認」，**不會**寫金額或替你確認已經入帳；要不要開發票、入帳了沒，由你自己查。

## ⑥ 合作提案｜進階

**主旨**：聯名合作提案

```
您好，

我們是白鷺插畫工作室，很喜歡你們幫咖啡店做的社群內容，
想跟貴公司談談明年的聯名合作，不知道下個月方便約個時間聊聊嗎？

白鷺插畫工作室 吳小姐
```

**預期**：意圖「其他」｜狀態「待確認草稿」｜草稿 yes

**你應該看到**：草稿有禮貌地回應，但**不會替你答應合作或約定時間**。

## ⑦ 改期（只有回覆草稿）｜基本

**主旨**：下週會議想改時間

```
您好，

原訂下週二（11/11）下午兩點的官網改版討論，我臨時要出差，
想改到 11/13（週四）或 11/14（週五）上午，不知道您哪天方便？

綠島旅行社 王經理
```

**預期**：意圖「改期」｜狀態「待確認草稿」｜草稿 yes

**你應該看到**：回覆草稿有禮貌地回應改期，但**不會替你決定日期**；具體時間標成【需人工確認】。

## ⑧ 客訴（只有回覆草稿，必須人工處理）｜基本

**主旨**：網站又打不開了，請處理

```
你們好，

我們診所的網站從昨天晚上就打不開，病患一直打電話來問。
這已經是這個月第二次了，我們付了年度維護費，
如果今天還是無法修好，我們要求退還這個月的費用。

青山牙醫診所 林院長
```

**預期**：意圖「客訴」｜狀態「需人工」｜草稿 yes

**你應該看到**：草稿先道歉、說明會盡快確認；**不會答應退費**，「退費要求」出現在【需人工確認】；沒有報價明細；除了「AI秘書/已處理」「AI秘書/客訴」，還會多貼「AI秘書/需人工」。

---

## ⑨ 退款要求（草稿不能答應退款）｜進階

**主旨**：活動取消，請退還訂金

```
您好，

原本 12/20 的活動攝影，因為場地出問題只好取消，
之前付的訂金請全額退還，麻煩盡快處理。

晨光瑜珈 周老師
```

**預期**：意圖「客訴」｜狀態「需人工」｜草稿 yes

**你應該看到**：退款要求會被當成客訴，一定要你親自決定。萬一 AI 在草稿裡寫了「會為您退款」這類承諾，程式會在草稿最上面加【需人工確認：回覆內文提到退款或賠償…】，紀錄狀態也是「需人工」。

## ⑩ 推銷／廣告（不建立草稿）｜進階

**主旨**：【限時優惠】SEO 網站排名衝刺方案

```
老闆您好，

本週限時優惠！SEO 網站排名衝刺方案，保證 30 天上首頁，
現在加入再送社群廣告投放教學一堂。

名額有限，把握機會。不想再收到這類訊息，請回覆「取消訂閱」。

晨星數位行銷
```

**預期**：意圖「其他」｜狀態「略過」｜草稿 no

**你應該看到**：沒有草稿；紀錄寫「系統依關鍵字判斷為推銷或廣告」。如果其實是你想回的信，自己回覆後把狀態改成「已回覆」。

## ⑪ 感謝信（不需要回覆）｜進階

**主旨**：謝謝你們，開幕很成功

```
您好，

上週開幕活動很順利，大家都很喜歡你們拍的照片，
真的很謝謝你們這段時間的協助！

星河咖啡 陳小姐
```

**預期**：意圖「其他」｜狀態「不需回覆」｜草稿 no

**你應該看到**：沒有草稿；紀錄寫「判斷為感謝或通知信，不需要回覆」。客戶筆記 `客戶/星河咖啡_陳小姐.md` 會同時列出 ① 和 ⑪ 兩筆紀錄。

## 檢核表
| 測試 | 預期 |
|---|---|
| Gmail「草稿」 | 有草稿的信（上表「草稿 yes」）各一封，開頭都有「【AI 草稿，寄出前請人工確認】」；⑩ ⑪ 沒有草稿 |
| 有沒有信被寄出？ | **沒有**（「寄件備份」裡不會多出信） |
| 報價金額 | 只出現在信末「報價明細」與報價單草稿，且與報價表算出來的一致；回覆內文沒有金額 |
| 退款 | 草稿不會答應退款；萬一寫了，最上面有【需人工確認】 |
| 試算表「秘書紀錄」 | 每封信一列，「狀態」與上表一致；「下一步」寫著你要做的事 |
| 雲端硬碟 `FinLab-Vault/秘書` | 每封信一篇紀錄（`<日期>-<意圖>-<客戶>.md`）；①②③④ 另外各有一份報價單草稿 |
| 雲端硬碟 `FinLab-Vault/客戶` | 每位客戶一篇；星河咖啡、綠島旅行社各有 2 筆紀錄 |
| 標籤 | 處理過的信從「AI秘書」換成「AI秘書/已處理」；⑧ ⑨ 另外貼「AI秘書/需人工」 |
| 狀態會自己變 | 把 ⑦ 的草稿寄出 → 下次按 ⑤ 後變「已回覆」；把 ⑥ 的草稿刪掉 → 變「已捨棄」 |
