# 範例 vault：我的財經知識庫

這個資料夾就是一個 **Obsidian vault**——說穿了只是一個裝滿 `.md` 純文字檔的資料夾。
用 Obsidian 打開最方便，但用 VS Code、Typora，甚至記事本也都看得懂，**資料不會被任何軟體綁住**。

## 兩種用法

| 用法 | 怎麼做 | 適合 |
|---|---|---|
| **課堂主線** | Stage 2 的「① 一鍵設定」會在你的 Google 雲端硬碟自動建立 `FinLab-Vault`（內容＝本資料夾的起始檔案，不含範例日報／秘書／標的／客戶；會建立空的 `標的/`、`客戶/` 與說明筆記），之後每天自動多一篇日報，標的與客戶筆記也會自動長出來 | 每個學員 |
| **先看範例** | Obsidian →「開啟資料夾作為 vault」→ 選這個 `obsidian-vault/` | 講師示範、想先看看長什麼樣子的人 |

完整步驟見 repo 的 `docs/student/student-stage-3-obsidian-lab.md`。

## 裡面有什麼

```
obsidian-vault/
├── 首頁.md                 ← 從這裡開始：待我處理的信＋最近日報（嵌入儀表板）＋快速前往
├── 日報總覽.base            ← Obsidian 核心外掛「Bases」的表格：把每篇日報的數字排成一張表
├── 秘書總覽.base            ← 秘書紀錄：待我處理、依狀態、依意圖、報價單草稿 四個檢視
├── 日報/                   ← Apps Script 每天自動寫入（這裡的 3 篇是虛構範例數字）：導覽、今日重點、原始數據、秘書待辦
├── 標的/                   ← 每個追蹤項目一篇（含說明.md）：欄位說明、走勢圖、近期走勢表、自己寫的段落
├── 秘書/                   ← 每封信一篇秘書紀錄＋報價單草稿（範例為虛構客戶）
├── 客戶/                   ← 每位客戶一篇，自動列出往來紀錄
├── 筆記/                   ← 你的每日筆記與每週回顧（自己寫觀察，不是 AI 寫）
├── 範本/每日筆記.md         ← 每日筆記範本（帶出今日重點、今天的秘書事項、觀察引導問題）
├── 範本/每週回顧.md         ← 每週回顧範本（這 7 天的日報、秘書紀錄、每日筆記＋回顧問題）
└── .obsidian/              ← 只放三個設定：每日筆記放「筆記/」、範本放「範本/」、關聯圖不顯示範本
```

## 小提醒

- 日報與報價單的**數字都由程式從資料表寫入**，AI 只寫摘要文字；「今日重點」與標的走勢圖也都是程式算的。
- 範例只有 3 篇日報（10-28～10-30），但標的筆記的走勢圖用的是 30 天的虛構「日報紀錄」（最後 3 天＝範例日報的數字），所以圖比下方的表格長，這是刻意的：避免放 30 篇範例日報讓 repo 變大。
- 走勢圖第一次顯示時，Obsidian 會問「Display Mermaid diagrams in this vault?」，按 **Allow**（內建功能，不是社群外掛）。
- `日報/`、`標的/`、`秘書/`、`客戶/`、`筆記/` 的範例都標了 `範例: true`，數字與公司皆為虛構，**不構成投資建議**。
- `首頁.md`、`範本/每日筆記.md`、`範本/每週回顧.md`、兩個 `.base`、`.obsidian/*.json` 與 `apps-script/Vault.gs` 的 `STARTER_FILES` 內容一致；`標的/說明.md` 與 `symbolFolderReadme_()` 一致。修改請兩邊一起改。
- 只用 Obsidian **內建**功能（每日筆記、範本、Bases、關聯圖），不需要安裝任何社群外掛。
