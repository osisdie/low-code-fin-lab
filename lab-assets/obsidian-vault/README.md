# 範例 vault：我的財經知識庫

這個資料夾就是一個 **Obsidian vault**——說穿了只是一個裝滿 `.md` 純文字檔的資料夾。
用 Obsidian 打開最方便，但用 VS Code、Typora，甚至記事本也都看得懂，**資料不會被任何軟體綁住**。

## 兩種用法

| 用法 | 怎麼做 | 適合 |
|---|---|---|
| **課堂主線** | Stage 2 的「① 一鍵設定」會在你的 Google 雲端硬碟自動建立 `FinLab-Vault`（內容＝本資料夾的起始檔案，不含範例），之後每天自動多一篇日報 | 每個學員 |
| **先看範例** | Obsidian →「開啟資料夾作為 vault」→ 選這個 `obsidian-vault/` | 講師示範、想先看看長什麼樣子的人 |

完整步驟見 repo 的 `docs/student/student-stage-3-obsidian-lab.md`。

## 裡面有什麼

```
obsidian-vault/
├── 首頁.md                 ← 從這裡開始：最近日報＋待確認報價單（嵌入儀表板）
├── 日報總覽.base            ← Obsidian 核心外掛「Bases」的表格：把每篇日報的數字排成一張表
├── 秘書總覽.base            ← 報價單草稿清單（客戶、合計、狀態）
├── 日報/                   ← Apps Script 每天自動寫入（這裡的 3 篇是虛構範例數字）
├── 秘書/                   ← 商務秘書產生的報價單草稿（範例為虛構客戶）
├── 筆記/                   ← 你的每日筆記（自己寫觀察，不是 AI 寫）
├── 標的/                   ← 每個追蹤項目一篇，日報會用 [[連結]] 連過來 → 關聯圖（Graph view）
├── 範本/每日筆記.md         ← 每日筆記範本（自動帶出當天日報）
└── .obsidian/              ← 只放三個設定：每日筆記放「筆記/」、範本放「範本/」、關聯圖不顯示範本
```

## 小提醒

- 日報與報價單的**數字都由程式從資料表寫入**，AI 只寫摘要文字。
- `日報/`、`秘書/` 的範例都標了 `範例: true`，數字與公司皆為虛構，**不構成投資建議**。
- `首頁.md`、`範本/每日筆記.md`、兩個 `.base`、`.obsidian/*.json` 與 `apps-script/Vault.gs` 的 `STARTER_FILES` 內容一致，修改請兩邊一起改。
- 只用 Obsidian **內建**功能（每日筆記、範本、Bases、關聯圖），不需要安裝任何社群外掛。
