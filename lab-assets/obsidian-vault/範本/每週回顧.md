# {{date:GGGG-[W]WW}} 每週回顧

> 「這週」＝上方 `日期` 往前算 7 天（含當天）。想回顧別週，把 `日期` 改成那週的最後一天，下面的表格會自動換。

## 這 7 天的日報

```base
filters:
  and:
    - file.inFolder("日報")
    - date(日期) > date(this.日期) - "7d"
    - date(日期) <= date(this.日期)
views:
  - type: table
    name: 這 7 天的日報
    order:
      - file.name
      - 美股開盤
      - USD_TWD
      - USD_TWD_漲跌
      - 台積電_2330
      - 台積電_2330_漲跌
      - BTC
      - BTC_漲跌
      - 待確認草稿
    sort:
      - property: 日期
        direction: ASC
```

## 這 7 天的秘書紀錄

```base
filters:
  and:
    - file.inFolder("秘書")
    - 類型 == "秘書紀錄"
    - date(日期) > date(this.日期) - "7d"
    - date(日期) <= date(this.日期)
views:
  - type: table
    name: 這 7 天的信
    groupBy:
      property: 狀態
      direction: ASC
    order:
      - file.name
      - 客戶
      - 意圖
      - 狀態
```

## 這 7 天的每日筆記

```base
filters:
  and:
    - file.inFolder("筆記")
    - 類型 == "每日筆記"
    - date(日期) > date(this.日期) - "7d"
    - date(日期) <= date(this.日期)
views:
  - type: table
    name: 這 7 天的筆記
    order:
      - file.name
    sort:
      - property: 日期
        direction: ASC
```
