# 保護你的 Gmail、API key 與知識庫

> 自動化要碰到信箱、AI 服務和你的筆記，最重要的是：**不要把鑰匙交給不該拿的人，也不要把資料留在不該放的地方。**

## 三種東西，三種保護法

| 東西 | 是什麼 | 本課程怎麼處理 |
|------|--------|----------------|
| Gmail 真實登入密碼 | 你帳號的總鑰匙 | **從頭到尾都不需要**。Apps Script 以「你的帳號授權」寄信 |
| Google 應用程式密碼 (App Password) | 給舊式程式用的 16 碼專用密碼，可單獨撤銷 | 主線不用；選修（SMTP／n8n）才用 |
| Gemini API key | 呼叫 AI 的鑰匙，外洩會被他人盜用額度 | 「一鍵設定」幫你存進 Apps Script「指令碼屬性」 |
| 客戶信件內容 | 別人的個資與商業資訊 | 課堂只用虛構信件；真實信件不送進免費 AI 方案 |
| 知識庫（FinLab-Vault） | 你的日報、觀察、報價單 | 留在你自己的雲端硬碟與電腦；不整包分享 |

## 做法

### 1. 主線：授權，而不是給密碼
第一次執行 Apps Script，Google 會跳出授權畫面，列出它要的權限（寄信、讀這份 Sheet、對外連線）。你同意的是「這份程式可以代你寄信」，**不是把密碼交給它**。不想用了，到 [Google 帳戶 → 安全性 → 第三方存取](https://myaccount.google.com/permissions) 移除即可。

### 1-1. 「Google 尚未驗證這個應用程式」是什麼？
第一次授權時會看到這個警告。原因是程式在**你自己的副本**裡，沒有送 Google 審查（個人小工具通常不會送審）。
- 確認是從**講師提供的連結**建立的副本，才點 **進階 → 前往（不安全）**。
- 來路不明的試算表跳出這個畫面，**不要點**。
- 知識庫功能需要雲端硬碟權限，授權畫面會寫「查看、編輯、建立及刪除你所有的雲端硬碟檔案」。這是 Apps Script 建立資料夾的最小可用權限；本課程程式**只讀寫 `FinLab-Vault` 資料夾**，原始碼在 `lab-assets/apps-script/Vault.gs`。
- 秘書功能需要 Gmail 權限，授權畫面會寫「讀取、撰寫、傳送及永久刪除郵件」。本課程程式**不會寄出或刪除**客戶信件，只建立草稿；原始碼公開在 `lab-assets/apps-script/Secretary.gs`，可以請懂程式的同事檢查。
- **公司 Workspace 帳號**可能被管理員擋掉這些權限，這是公司的資安政策，不要想辦法繞過；課堂請用個人帳號。

### 2. 選修：一定要用 App Password 時
- 先開啟「兩步驟驗證」，再到 https://myaccount.google.com/apppasswords 建立專用密碼。
- 只放在 `.env`（本 repo 已 gitignore，範本見 `.env.example`），不要貼進程式碼或聊天室。
- 不用時到同一頁撤銷。
- **絕對不要把真實登入密碼填進任何工具。**

### 3. API key
- 用「① 一鍵設定」貼上，它會存進指令碼屬性；不要寫在 `Code.gs` 或表格儲存格。
- 拿到 Sheet **編輯權**的人看得到指令碼屬性，所以分享只給「檢視」權限，或乾脆不分享。
- 截圖前先檢查有沒有露出 key。
- 外洩或不確定時：到 AI Studio 刪除並重建，再跑一次「① 一鍵設定」換新 key。

### 4. 客戶信件與免費 AI
- **Gemini API 免費方案的輸入內容可能被 Google 用於改進服務**（以官網條款為準，查證日期 2026-10-31）。
- 課堂只用 `lab-assets/secretary/sample-emails.md` 的虛構信件。
- 回到工作上：真實客戶信件請改用付費方案或公司核准的 AI 工具，並先問過 IT／法務。

### 5. 知識庫（Obsidian vault）
- vault 就是一個資料夾：誰拿到資料夾，誰就看得到全部內容。不要把整個 `FinLab-Vault` 分享出去；要分享就只挑單一 `.md` 檔。
- 選修的 AI 外掛會把 key 存在 `.obsidian/plugins/` 底下，這也是不要整包分享的原因之一。
- 只安裝下載量高、有在維護的社群外掛；主線完全不需要外掛。

## 分享前檢查清單
- [ ] 程式碼裡沒有 key 或密碼
- [ ] 截圖沒有露出指令碼屬性的值
- [ ] 沒有把 `.env` 上傳到 GitHub（`git status` 看不到它）
- [ ] 分享 Sheet 時，只給「檢視」權限
- [ ] 秘書練習用的是虛構信件
- [ ] 沒有把整個 `FinLab-Vault`（含 `.obsidian/`）分享給別人
