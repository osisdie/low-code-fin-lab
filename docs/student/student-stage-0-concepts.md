# Stage 0 — 先搞懂 AI Agent，再用 5 分鐘做出第一個每日任務

> 目標：知道「AI 數位分身」是由哪幾塊組成、「全自動」能做到哪裡，並親手建立第一個每日自動任務。
> 需要：一個免費的 ChatGPT 帳號（手機或電腦皆可）。不需要訂閱。

## 你每天是不是都在做這些？
- 查美元、日圓、歐元匯率
- 看台積電、聯發科等股票
- 看黃金、比特幣、美國十年期公債殖利率
- 看今天有什麼 AI 新聞影響股價

還有這些：
- 客戶來信詢價，要翻價目表、算金額、寫一封有禮貌的回信
- 會議改期、客訴，每封都要斟酌用詞

**每天查、每天整理、每天重複一次** —— 這種事最適合交給 AI Agent。今天我們做兩個分身：**24H 市場情報站**（Stage 1–3）和**私人商務秘書**（Stage 4）。

## Agent 是什麼？（白話版）
聊天機器人是「你問、它答」。Agent 是「**自己會按時去做事**」。今天所有的 Agent 都由這五塊組成：

| 積木 | 做什麼 | 你之後會用到 |
|------|--------|--------------|
| ① 排程 | 每天固定時間啟動 | ChatGPT Tasks／Apps Script 觸發器 |
| ② 取資料 | 去查最新數字、讀來信 | 網路搜尋／Google Finance／CoinGecko／Gmail 標籤 |
| ③ 整理 | 把數字、信件變成易讀的文字 | ChatGPT／OpenRouter 免費模型 |
| ④ 推送 | 送到你看得到的地方 | app 通知／每天一封「今日總覽」（財經＋秘書待辦）／Gmail 草稿 |
| ⑤ 存檔 | 留下來、可累積、可回頭比較 | 試算表「日報紀錄」「秘書紀錄」／Markdown 資料夾＋Obsidian |

> 📌 老師原本用 Grok Automation 一次包辦前四塊，很方便；但你不一定有訂閱。接下來我們用免費工具，自己把五塊接起來。

## 「全自動」能做到哪裡？
| 可以全自動 | 一定留給人 |
|---|---|
| 每天定時抓數字、整理成日報、寄到信箱、存進知識庫 | 解讀行情、做投資決定（報告**不給投資建議**） |
| 判讀客戶來信、寫好回覆草稿、算好報價單 | 按下「傳送」、決定折扣／交期／退款 |

> 一句話：**整理和起草全自動，決定和寄出靠你。** 這不是功能不夠，而是目前最安全、也最符合實務的做法。

## 5 分鐘暖身：建立第一個每日任務
1. 登入 ChatGPT（免費帳號即可）。
2. 貼上這段（也在 `lab-assets/prompts/01-stage0-warmup-task.txt`）：

   ```
   每天早上 8 點，上網查今天的 USD/TWD 匯率與台積電（2330）股價，各用一行告訴我數字和比前一個交易日漲跌幾 %。查不到的就直接說查不到，不要猜。
   ```
3. ChatGPT 會詢問是否建立排程任務，確認即可。到「任務／Tasks」頁面可看到它。
4. 想立刻看效果，在任務頁選擇立即執行一次（介面名稱可能不同，以畫面為準）。

- ✅ **檢核點**：任務列表看得到你的每日任務，並收到一次結果。
- ⚠️ 免費帳號的任務數量有上限（撰寫時為 **3 個**，查證日期 2026-10-03，以官網為準），所以不要把名額浪費在試玩；試完可刪除。
